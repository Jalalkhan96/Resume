# Resume

A personal resume / profile page written in plain HTML — tables and anchor-linked sections, no CSS or JavaScript files.

## What it is

A single-page resume site built with semantic HTML only. A header table pairs a profile photo (loaded from the author's GitHub avatar) with a short self-introduction, above a small nav list that jumps to the page's sections. The **Education** section presents schooling history as a bordered table (grade, school, place, percentage); **Study** describes the author's current BS Software Engineering studies; **Projects** lists project entries (Physics, Coding, Game), partly filled with placeholder text. A contact footer and a "Back To Top" link close the page, and the header also links to a second page, `About us.html`. One gap to know: the page references an image file `ffffff.PNG` that is not in this repo, so that one image does not load.

## Files

- `index.html` — the resume page itself: header, nav, Education / Study / Projects sections, and contact footer.
- `About us.html` — a secondary "About Us" page linked from the header, currently filled with placeholder (lorem ipsum) paragraphs plus contact links.
- `README.md` — this file.

## Run it

Open `index.html` in a browser. An internet connection is needed for the header photo, which loads from GitHub's avatar service.
